# Wire model inventory

This contributor map points each model responsibility to its schema, generated Go package, generator, and active transport. `go test ./tools/protocols` enumerates the named schema components and checks their generated Go definitions; it also keeps explicit origins for the signaling union and anonymous nested types. Regeneration drift is checked by `make generate-api` in CI.

## Generated and adapted definitions

`TestGeneratedWireModelInventoryCoversEveryNamedComponent` checks each named REST, FCM, public projection, and signaling component against a generated Go declaration. Modelina acronym spelling is normalized in that test. Its explicit signaling mappings cover anonymous types at `SignalingInboundDiscriminator.method`, `ServerCloseReason.code`, `ServerRPCBody.command`, and `PTZContinuousWireCommand.method`, plus message/channel unions. The conditional `ClientEnvelope`, PTZ validation-only `PTZRPC`, RPC response alternatives, and historical `Heartbeat` shape are represented by their generated frame/value models and custom validation paths rather than standalone Go declarations.

Small handwritten types remain where their public shape or decoder has behavior. `DeviceDetail` and `LocationList` keep operation-set adapters around generated projections. `ringtypes.BatteryReading` and `ringtypes.OwnerID` preserve observed scalar decoding and are attached to named public schema components through `x-go-type`. `SignalingConnection.Message` preserves raw bodies while reading its discriminator through the generated model. The public `PushFilter`, `PushFilters`, `PushEvent`, `PTZResult`, and `SessionDescription` adapters are checked against their AsyncAPI field inventories by `TestHandwrittenPublicSignalingAdaptersMatchGeneratedSchemaFields`.

`TestGeneratedSignalingFieldConstantsComeFromAsyncAPISchema` verifies every generated `protocol.Field*` constant is a schema property. `TestGeneratedFCMPushKeyConstantsComeFromExternalSchema` and `TestMCSAppDataCryptoKeysComeFromProtocolInventory` trace nested FCM JSON and MCS AppData keys to their responsibility-specific sources and prevent handwritten literals in active decoders. `TestGeneratedPublicProjectionValuesComeFromSchema` verifies the public open-enum constants against their projection schemas and prevents inline values in SDK adapters. `TestSignalingTransportDoesNotDefineHandwrittenWireStructsOrLiteralKeys` rejects tagged wire structs and literal map/index/required-key strings in the signaling decode boundaries. The companion negative tests prove that handwritten frame fields and both registered or unregistered nested keys fail the gate, while caller-supplied dynamic map keys and generated constants remain accepted. `TestKnownSignalingValuesUseGeneratedProtocolConstants` prevents runtime code from spelling known methods, enum values, or discriminators inline.
