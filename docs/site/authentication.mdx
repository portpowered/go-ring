---
title: Authentication and tokens
description: Complete Ring's two-factor login flow, then pass account credentials with each request.
---

`go-ring` does not keep an account's access token or refresh token on the
shared `Client`. Create an isolated login session for the initial OAuth and
two-factor exchange, save the returned tokens securely, and pass an
`AuthContext` to each account operation.

Ring authentication does not support browser CORS. Run this flow in a trusted
backend, never in browser JavaScript.

## Complete the two-factor flow

Use the same `LoginSession` to request a verification code and submit it. The
session retains the OAuth state, cookies, and PKCE verifier needed to finish
that exchange.

```go
login, err := client.NewLoginSession(ring.LoginSessionRequest{
	Username: username,
	Password: password,
})
if err != nil {
	return err
}
defer login.Close()

if err := login.Request2FACode(ctx); err != nil {
	return err
}

tokens, err := login.Authenticate(ctx, ring.CompleteLoginRequest{OTPCode: otpCode})
if err != nil {
	return err
}
auth := ring.AuthContext{
	AccessToken: tokens.AccessToken,
	HardwareID:  login.HardwareID(),
}
```

Store the complete token response, including the refresh token and the
hardware ID. Restrict access to the stored secrets and never log credentials,
verification codes, or tokens.

## Use and refresh tokens

Pass the account context with each request. A single `Client` can serve more
than one account because authentication is supplied per operation.

```go
devices, err := client.ListDevices(ctx, ring.ListDevicesRequest{Auth: auth})
if err != nil {
	return err
}
```

Refresh tokens rotate. Replace the stored response after every successful
refresh:

```go
tokens, err := client.RefreshToken(ctx, ring.RefreshTokenRequest{
	RefreshToken: stored.RefreshToken,
	HardwareID:   hardwareID,
})
if err != nil {
	return err
}
// Persist the complete tokens response before discarding the old one.
```

For the full authentication example, see
[`examples/token-exchange`](https://github.com/portpowered/go-ring/tree/main/examples/token-exchange).
