These guides explain the main customer workflows in `go-ring`. The generated
API reference describes the HTTP and signaling contracts; the guides show how
to use the public Go client around those operations.

- [Discover devices and send controls](/docs/guides/device-operations)
- [Open and manage a live session](/docs/guides/live-sessions)

- [Receive FCM and signaling push notifications](/docs/guides/push-notifications)

The runnable programs in the repository's `examples/` directory provide
complete versions of several workflows, including token exchange, device
enumeration, live streaming, PTZ, and signaling push events.

## Evidence and compatibility

Ring's endpoints and message formats are not a stable public protocol. The
guides describe the behavior implemented by this library and identify where
the evidence is narrower. Live signaling and WebRTC flows are backed by
sanitized captures and replay checks. FCM HTTP registration examples are
source-derived reference behavior, and sample FCM notification payloads are
synthetic. Those sources are not a guarantee for every account, device, or
region.
