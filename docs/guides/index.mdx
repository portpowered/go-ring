These guides explain the main customer workflows in `go-ring`. The generated
API reference describes the HTTP and signaling contracts; the guides show how
to use the public Go client around those operations.

- [Browse locations and inspect status](/docs/guides/locations-and-status)
- [Fetch snapshots and unlock an intercom](/docs/guides/snapshots-and-intercom)
- [Browse and manage recordings](/docs/guides/recordings-and-timeline)

- [Negotiate cloud playback](/docs/guides/cloud-playback)

The runnable programs in the repository's `examples/` directory provide
complete versions of several workflows, including token exchange, device
enumeration, live streaming, PTZ, and signaling push events.

## Compatibility

Ring's endpoints and message formats can change, and behavior may vary by
account, device, and region. Handle unavailable operations and errors in your
application.
