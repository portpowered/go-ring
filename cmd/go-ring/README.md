# go-ring diagnostic CLI

This separate Go module imports the public `github.com/portpowered/go-ring/pkg/ring`
package. Build it from this directory with `go build .` or run it with
`go run .`.

Commands, credential handling, live video, and offline playback are covered
in the [diagnostic CLI guide](https://portpowered.github.io/go-ring/docs/guides/diagnostic-cli/).
